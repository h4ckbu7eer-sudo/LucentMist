# LucentMist 0.9.8 发布说明

状态：修正版发布准备中，尚待本次CI和GHCR产物复验。

0.9.7在真实发布镜像上完成了扫描，但模型结论仍误述证书到期年份和受检端口范围，见[未通过记录](release-artifact-validation-0.9.7.md)。因此另发0.9.8，保留0.9.7标签，不以本地测试冒充发布产物通过。

## 用户可见修复

- 包含0.9.6之后的完成度收敛、HTTP HEAD/GET、DNS共享快照、历史云线索折叠、默认精简呈现。
- 端口范围守卫不局限RDP，且双向检查：未扫端口不能断言关闭，已扫端口不能列为未检查。
- 证书有效期以`ssl_check.notAfterUtc`为准，在模型观察和工具核验事实中显示精确UTC日期；矛盾到期年份触发有预算的结论纠正，不重复网络扫描。
- 新增通用性与真实产物残留回归合计26例；本地共590个.NET测试、14个Python测试。模型契约合格不等于事实正确。

## 部署与边界

使用0.9.8标签或经核实的不可变digest；升级前备份明文SQLite数据。非回环部署必须设置强API/Web凭据；模型key只放受保护环境，不写入仓库、Docker配置、报告或命令行。仅扫描已授权目标。

网关结果仍是暴露面、TLS信任风险、线索与建议，不是确认CVE；固件不公开、云源失败/限流、DNS扫描视角和容器网络视角仍限制结论。模型与断言守卫不保证所有自然语言变体永远正确。旧版本保留，但0.9.7有本次记录的语义问题，不能把回滚理解为修复。
