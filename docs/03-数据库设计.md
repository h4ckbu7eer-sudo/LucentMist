# LucentMist 数据库设计

## 1. 存储方案

| 存储 | 引擎 | 用途 |
|------|------|------|
| 持久化 | SQLite | 扫描记录、设备清单、配置 |
| 缓存 | Redis | 会话状态、临时扫描结果、LLM 上下文 |
| 内存 | Dictionary | 短期记忆、工具注册表 |

## 3. 表结构

### 3.1 scan_tasks（扫描任务表）

```sql
CREATE TABLE scan_tasks (
    id          TEXT PRIMARY KEY,          -- UUID
    target      TEXT NOT NULL,              -- 目标子网/IP，如 192.168.1.0/24
    scan_type   TEXT NOT NULL,              -- ping / port / service / full
    status      TEXT NOT NULL DEFAULT 'pending',  -- pending/running/completed/failed
    created_at  TEXT NOT NULL,              -- ISO 8601
    started_at  TEXT,
    completed_at TEXT,
    total_devices INTEGER DEFAULT 0,
    error_message TEXT
);
```

### 3.2 scan_results（扫描结果表）

```sql
CREATE TABLE scan_results (
    id          TEXT PRIMARY KEY,          -- UUID
    task_id     TEXT NOT NULL,              -- FK -> scan_tasks.id
    ip_address  TEXT NOT NULL,              -- 目标 IP
    mac_address TEXT,                       -- MAC 地址（存活扫描可得）
    hostname    TEXT,                       -- 主机名
    is_alive    INTEGER NOT NULL DEFAULT 0, -- 是否在线
    latency_ms  REAL,                       -- 延迟(毫秒)
    open_ports  TEXT,                       -- JSON: [80, 443, 22, ...]
    os_guess    TEXT,                       -- 操作系统猜测
    raw_data    TEXT,                       -- 原始输出(JSON)
    created_at  TEXT NOT NULL               -- ISO 8601
);

CREATE INDEX idx_scan_results_task ON scan_results(task_id);
CREATE INDEX idx_scan_results_ip ON scan_results(ip_address);
```

### 3.3 devices（设备表）

```sql
CREATE TABLE devices (
    id          TEXT PRIMARY KEY,          -- UUID
    ip_address  TEXT NOT NULL,
    mac_address TEXT,
    hostname    TEXT,
    vendor      TEXT,                       -- MAC OUI 识别厂商
    device_type TEXT,                       -- router / laptop / phone / iot / unknown
    first_seen  TEXT NOT NULL,              -- 首次发现时间
    last_seen   TEXT NOT NULL,              -- 最后在线时间
    is_active   INTEGER NOT NULL DEFAULT 1,
    tags        TEXT                        -- JSON: ["gateway", "critical"]
);

CREATE UNIQUE INDEX idx_devices_ip ON devices(ip_address);
CREATE INDEX idx_devices_type ON devices(device_type);
```

### 3.4 services（服务表）

```sql
CREATE TABLE services (
    id          TEXT PRIMARY KEY,
    device_id   TEXT NOT NULL,              -- FK -> devices.id
    port        INTEGER NOT NULL,
    protocol    TEXT NOT NULL DEFAULT 'tcp', -- tcp / udp
    service_name TEXT,                      -- http / ssh / mysql / unknown
    banner      TEXT,                       -- 服务 Banner
    version     TEXT,                       -- 版本号
    ssl_info    TEXT,                       -- SSL证书信息(JSON)
    first_seen  TEXT NOT NULL,
    last_seen   TEXT NOT NULL
);

CREATE INDEX idx_services_device ON services(device_id);
CREATE INDEX idx_services_port ON services(port);
```

### 3.5 alerts（告警表）

```sql
CREATE TABLE alerts (
    id          TEXT PRIMARY KEY,
    device_id   TEXT,                       -- FK -> devices.id (可空)
    alert_type  TEXT NOT NULL,              -- new_device / offline / port_change / security
    severity    TEXT NOT NULL DEFAULT 'info', -- info / warning / critical
    title       TEXT NOT NULL,
    description TEXT,
    is_read     INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT NOT NULL
);

CREATE INDEX idx_alerts_device ON alerts(device_id);
CREATE INDEX idx_alerts_severity ON alerts(severity);
```

### 3.6 agent_sessions（Agent 会话表）

```sql
CREATE TABLE agent_sessions (
    id          TEXT PRIMARY KEY,
    title       TEXT,                       -- 会话标题（AI 生成）
    model       TEXT NOT NULL,              -- 使用的 LLM 模型
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL,
    message_count INTEGER DEFAULT 0,
    summary     TEXT                        -- 会话摘要
);
```

### 3.7 agent_messages（Agent 消息表）

```sql
CREATE TABLE agent_messages (
    id          TEXT PRIMARY KEY,
    session_id  TEXT NOT NULL,              -- FK -> agent_sessions.id
    role        TEXT NOT NULL,              -- user / assistant / system / tool
    content     TEXT NOT NULL,
    tool_calls  TEXT,                       -- JSON: 工具调用记录
    created_at  TEXT NOT NULL
);

CREATE INDEX idx_messages_session ON agent_messages(session_id);
```

## 4. Redis 缓存设计

| Key Pattern | 类型 | 用途 | TTL |
|-------------|------|------|-----|
| `scan:{taskId}:status` | String | 扫描任务状态 | 1h |
| `scan:{taskId}:results` | List | 扫描结果流 | 1h |
| `agent:{sessionId}:context` | List | 对话上下文 | 30min |
| `agent:{sessionId}:memory` | Hash | 短期记忆 | 1h |
| `device:{ip}` | Hash | 设备实时状态 | 5min |
