# LucentMist 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
LucentMist — 基于 ReAct 模式的智能网络分析助手

### 1.2 项目定位
LucentMist 是一个融合网络扫描工具与 AI 推理能力的智能网络分析助手。基于 ReAct（Reasoning + Acting）模式，通过 LLM 驱动的推理引擎自动分析网络环境，发现设备、识别服务、检测漏洞，并以自然语言与用户交互。

### 1.3 目标用户
- 网络管理员 / IT 运维人员
- DevOps 工程师
- 安全研究人员
- 个人技术爱好者

### 1.4 核心价值
- **AI 驱动**：LLM 自动推理扫描结果，生成可读的分析报告
- **插件化工具**：网络扫描工具可独立使用，也可被 Agent 调用
- **双模式交互**：CLI 命令行 + REST API
- **本地优先**：支持 Ollama 本地推理，数据不出本地网络

## 2. 功能需求

### 2.1 网络扫描 (P0 - 核心)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| F-01 | 存活探测 | ICMP Ping / TCP SYN 探测局域网设备 | P0 |
| F-02 | 端口扫描 | TCP/UDP 端口扫描，支持范围/列表 | P0 |
| F-03 | 服务识别 | Banner 抓取，识别 HTTP/SSH/MySQL 等服务 | P0 |
| F-04 | 指纹采集 | HTTP 响应头、SSL/TLS 证书信息提取 | P1 |
| F-05 | 子网扫描 | 支持 CIDR 格式子网（如 192.168.1.0/24） | P0 |

### 2.2 AI 智能体 (P0 - 核心)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| F-06 | ReAct 推理 | 推理→行动→观察循环，自主决策扫描策略 | P0 |
| F-07 | LLM 切换 | 支持 Ollama (本地) / Claude API (云端) 切换 | P0 |
| F-08 | 智能对话 | 自然语言交互，如"扫描我的网络并分析安全风险" | P0 |
| F-09 | 分析报告 | AI 生成格式化的网络安全分析报告 | P1 |
| F-10 | 上下文记忆 | 跨轮次记忆，持续追踪网络变化 | P1 |

### 2.3 交互接口 (P0)

| ID | 功能 | 描述 | 优先级 |
|----|------|------|--------|
| F-11 | CLI 命令 | scan / ssl-check / agent / config / status / help 子命令 | P0 |
| F-12 | REST API | 扫描任务、Agent 对话、状态查询接口 | P1 |
| F-13 | 配置管理 | JSON 配置文件，LLM 提供商/扫描参数配置 | P0 |

## 3. 非功能需求

### 3.1 性能
- 单次 /24 子网存活扫描 < 30 秒
- 端口扫描 100 端口 < 60 秒
- LLM 推理响应 < 10 秒（本地 Ollama，7B 模型）

### 3.2 可靠性
- 扫描失败自动重试（最多 3 次）
- LLM 调用失败降级到备用 Provider

### 3.3 安全性
- 端口扫描限速（防止网络拥塞）
- 配置文件敏感信息加密存储
- API 接口鉴权（Bearer Token）

### 3.4 可扩展性
- 工具插件化（实现 ITool 接口即可注册）
- LLM Provider 可插拔（实现 ILLMProvider 接口）
- 记忆存储可切换（SQLite / Redis / 内存）

## 4. 用户故事

### US-01: 网络管理员快速扫描
> 作为一名网络管理员，我希望能快速扫描公司内网，知道有哪些设备在线、开放了哪些端口。

### US-02: 安全分析助手
> 作为一名安全研究员，我希望 AI 能帮我分析扫描结果，指出潜在的安全风险并给出修复建议。

### US-03: 自然语言交互
> 作为一名技术爱好者，我希望用自然语言说"帮我看下路由器开了哪些端口"，而不是记住复杂的命令参数。

## 5. 约束与限制

- 运行环境：Windows 10+ / Linux (Ubuntu 20.04+) / macOS 12+
- .NET 8.0 运行时
- 端口扫描需要 root/管理员权限（部分模式）
- Ollama 本地推理需要 GPU 或 ≥ 8GB RAM
