# LucentMist 贡献指南

## 开发环境
- .NET 8.0 SDK
- 推荐 IDE: VS Code / JetBrains Rider / Visual Studio 2022

## 项目结构
```
src/LucentMist.Core/     ← 核心抽象层，零外部依赖
src/LucentMist.Tools/    ← 网络工具实现（实现 ITool）
src/LucentMist.Agent/    ← ReAct AI 智能体
src/LucentMist.CLI/      ← 命令行入口
src/LucentMist.API/      ← REST API
tests/                   ← 测试 (xUnit)
```

## 添加新工具
1. 在 `src/LucentMist.Tools/` 下创建类，实现 `ITool`
2. 在 `AgentServiceCollectionExtensions.cs` 中注册
3. 在 `src/LucentMist.CLI/CliApp.cs` 中注册到 toolRegistry
4. 编写单元测试（`tests/LucentMist.Tools.Tests/`）

## 提交流程
1. Fork 项目
2. 创建 feature 分支: `git checkout -b feature/xxx`
3. 提交代码: `git commit -m "feat: xxx"`
4. 确保测试通过: `dotnet test`
5. 提交 PR

## 提交规范
```
feat:     新功能
fix:      修复 Bug
docs:     文档更新
test:     测试
refactor: 重构
chore:    构建/工具
```
