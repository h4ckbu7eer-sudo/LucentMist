# LucentMist 编码规范

## 1. 命名规范

### 1.1 C# 命名

```csharp
// 类/方法/属性: PascalCase
public class PortScanTool : ITool { }
public async Task<ScanResult> ScanAsync() { }
public string IpAddress { get; set; }

// 接口: I 前缀
public interface ITool { }
public interface ILLMProvider { }

// 私有字段: _camelCase
private readonly IToolRegistry _toolRegistry;
private int _scanCount;

// 常量: PascalCase
public const int DefaultTimeout = 5000;

// 参数/变量: camelCase
var scanResult = await scanner.ScanAsync(target);
```

### 1.2 文件命名

```
类文件: 与类名一致
  PortScanTool.cs
  ReActEngine.cs
  ILLMProvider.cs

测试文件: {测试类名}Tests.cs
  PortScanToolTests.cs
  ReActEngineTests.cs

配置文件: kebab-case
  appsettings.json
  system_prompt.txt
```

## 3. 编码规则

### 3.1 异步

```csharp
// ✅ 正确: async 方法名以 Async 结尾
public async Task<ScanResult> ExecuteAsync() { }

// ❌ 错误: 不要使用 .Result 或 .Wait()
var result = scanTask.Result;  // 死锁风险

// ✅ 正确: 使用 await
var result = await scanTask;
```

### 3.2 异常处理

```csharp
// ✅ 正确: 捕获具体异常
try
{
    await scanner.ScanAsync(target);
}
catch (ScanTimeoutException ex)
{
    _logger.LogError(ex, "扫描超时: {Target}", target);
    throw new ScanException("扫描超时，请缩小目标范围", ex);
}

// ❌ 错误: 吞掉异常
try { ... } catch { }
```

### 3.3 依赖注入

```csharp
// ✅ 正确: 通过接口注入
public ReActEngine(ILLMProvider llm, IToolRegistry tools, ILogger<ReActEngine> logger)
{
    _llm = llm;
    _tools = tools;
    _logger = logger;
}

// ❌ 错误: 直接 new 具体类
var ollama = new OllamaProvider("http://..."); // 硬编码
```

### 3.4 日志

```csharp
// ✅ 正确: 结构化日志
_logger.LogInformation("扫描开始: Target={Target}, Type={ScanType}", target, scanType);
_logger.LogWarning("设备离线: IP={IpAddress}", ip);

// ❌ 错误: 字符串拼接
_logger.LogInformation("扫描开始: " + target);
```

## 4. 测试规范

```csharp
public class PortScanToolTests
{
    // AAA 模式: Arrange → Act → Assert
    [Fact]
    public async Task ScanAsync_ValidTarget_ReturnsOpenPorts()
    {
        // Arrange
        var tool = new PortScanTool(Mock.Of<ILogger<PortScanTool>>());
        
        // Act
        var result = await tool.ScanAsync("127.0.0.1", new[] { 80, 443 });
        
        // Assert
        Assert.NotNull(result);
        Assert.True(result.OpenPorts.Length > 0);
    }
}
```

## 5. Git 提交规范
