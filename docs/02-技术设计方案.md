# LucentMist 技术设计方案

## 1. 架构概述

采用 **分层架构 + Actor 模型**，五层结构：

```
┌──────────────────────────────────────┐
│         CLI / API (交付层)            │
├──────────────────────────────────────┤
│         Agent (AI 智能体层)            │
│    ReAct 引擎 + LLM Provider          │
├──────────────────────────────────────┤
│         Tools (网络工具层)             │
│    扫描器 / 指纹采集 / 服务识别         │
├──────────────────────────────────────┤
│         Core (核心抽象层)              │
│    Actor系统 / 记忆 / 会话 / 数据模型   │
├──────────────────────────────────────┤
│         基础设施 (Infrastructure)       │
│    SQLite / Redis / Akka.NET          │
└──────────────────────────────────────┘
```

## 2. 技术选型

| 组件 | 技术 | 版本 | 理由 |
|------|------|------|------|
| 运行时 | .NET | API/Web/tests `net10.0`；Core/Tools/Agent/Scanning/CLI `net8.0` | 宿主与测试统一 10.0，纯库保持 8.0 |
| Actor 模型 | Akka.NET | 1.5+ | 成熟稳定的 Actor 框架 |
| 数据库 | SQLite | 3.x | 轻量本地存储 |
| 缓存 | Redis | 7.x | 高性能临时数据/会话 |
| LLM 客户端 | HttpClient + JSON | - | 直接调用 REST API |
| 网络扫描 | System.Net.* / 原生调用 | - | 平台原生网络能力 |
| 测试 | xUnit v3 | 3.x | 现代 .NET 测试框架 |
| 序列化 | System.Text.Json | 8.x | 高性能 JSON |

## 4. 核心设计模式

### 4.1 ReAct 模式

```
┌─────────────────────────────────┐
│           ReAct Loop             │
│                                 │
│  Observation → Thought → Action  │
│       ↑                    ↓    │
│       └────────────────────┘    │
│         (反馈循环，最大 N 轮)     │
└─────────────────────────────────┘

每轮：
1. Thought: LLM 分析当前观察，决定下一步
2. Action: 调用对应工具（扫描/查询）
3. Observation: 将工具结果作为新观察反馈
4. 检查是否到达终止条件
```

### 4.2 工具注册模式

```csharp
public interface ITool
{
    string Name { get; }
    string Description { get; }
    ToolParameter[] Parameters { get; }
    Task<ToolResult> ExecuteAsync(ToolArguments args);
}

// 注册
services.AddTool<PortScanTool>();
services.AddTool<PingScanTool>();
services.AddTool<ServiceIdentifyTool>();
services.AddTool<UdpScanTool>();
services.AddTool<SslCertificateTool>();
```

### 4.3 LLM Provider 策略模式

```csharp
public interface ILLMProvider
{
    Task<string> ChatAsync(string prompt, List<Message> history);
    Task<string> ReActAsync(string thought, List<Tool> tools);
}

// 切换
class OllamaProvider : ILLMProvider { }
class ClaudeProvider : ILLMProvider { }
```

## 5. 数据流

```
用户输入 "扫描 192.168.1.0/24 并分析安全风险"
         │
         ▼
    CLI/API 接收
         │
         ▼
    Agent.ReAct()
         │
    ┌────▼────┐
    │ Thought  │  LLM: "需要先做存活扫描"
    └────┬────┘
         │
    ┌────▼────┐
    │ Action   │  调用 PingScanTool
    └────┬────┘
         │
    ┌────▼────┐
    │ Observe  │  结果: 发现 15 台设备
    └────┬────┘
         │
    ┌────▼────┐
    │ Thought  │  LLM: "对每台设备做端口扫描"
    └────┬────┘
         │
    ┌────▼────┐
    │ Action   │  调用 PortScanTool × 15
    └────┬────┘
         │
    ┌────▼────┐
    │ Observe  │  结果: 开放端口列表
    └────┬────┘
         │
    ┌────▼────┐
    │ Thought  │  LLM: "检查 UDP 服务"
    └────┬────┘
         │
    ┌────▼────┐
    │ Action   │  调用 UdpScanTool
    └────┬────┘
         │
    ┌────▼────┐
    │ Observe  │  结果: DNS/NTP 服务信息
    └────┬────┘
         │
    ┌────▼────┐
    │ Thought  │  LLM: "分析完成，生成报告"
    └────┬────┘
         │
         ▼
    返回分析报告给用户
```

### 5.1 UDP 扫描模块

UDP 端口扫描通过发送协议特定的探测包判断端口是否开放：

- **端口范围解析**：支持逗号分隔和范围混合格式（`53,67-69,161`）
- **并发控制**：SemaphoreSlim 限流，默认 20 并发
- **协议探测**：DNS/SNMP/NTP 发送对应协议包，其他端口发送空包
- **服务识别**：内置 11 种常见 UDP 服务映射
- **超时处理**：每个端口独立超时，避免整体阻塞

### 5.2 SSL 证书校验模块

通过 TCP + SslStream 获取目标 SSL/TLS 证书信息：

- 连接后发起 TLS 握手，提取 X.509 证书
- 自动判断证书是否过期、剩余天数
- 输出颁发者、主题、指纹等完整信息

## 6. 项目引用关系

```
LucentMist.CLI ──────> LucentMist.Agent
LucentMist.API ──────> LucentMist.Agent
LucentMist.API ──────> LucentMist.Scanning
LucentMist.Web ──────> LucentMist.Scanning
LucentMist.Web ──────> LucentMist.Agent
LucentMist.Web ──────> LucentMist.Tools
LucentMist.Web ──────> LucentMist.Core
LucentMist.Scanning ─> LucentMist.Tools
LucentMist.Agent ────> LucentMist.Tools
LucentMist.Agent ────> LucentMist.Core
LucentMist.Tools ────> LucentMist.Core
```

即：
- Core 无外部依赖（纯抽象）
- Tools 依赖 Core
- Scanning 依赖 Tools（后台队列与持久化）
- Agent 依赖 Core + Tools
- API 依赖 Agent + Scanning
- Web 依赖 Agent + Scanning + Tools + Core
- CLI 依赖 Agent
