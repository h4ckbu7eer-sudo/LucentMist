### 已知问题
- OLLAMA_NOT_CONFIGURED: Agent 功能需要配置 LLM Provider（设计如此，非 Bug）
- TCP_SCAN_MODE_ONLY: 端口扫描仅支持 TCP Connect 模式（SYN 扫描未来版本）
- IPV4_ONLY: 当前仅支持 IPv4（IPv6 在路线图中）
- WINDOWS_ICMP_PERMISSION: Windows 上 ICMP Ping 可能需管理员权限

## 发布步骤

```bash
# 1. 确认状态
git status
dotnet build -c Release
dotnet test

# 2. 创建发布
scripts/build-release.sh  # 或 build-release.ps1

# 3. 验证产物
./publish/cli/lmist status

# 4. 创建 Git Tag
git tag -a v0.1.0 -m "Release v0.1.0"
git push origin v0.1.0
```
