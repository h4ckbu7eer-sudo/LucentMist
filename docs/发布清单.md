## 发布命令

```bash
dotnet restore --locked-mode
dotnet format --verify-no-changes --no-restore
dotnet build -c Release --no-restore
dotnet test -c Release --no-build
docker compose config --quiet
git diff --check

git push origin main
git tag -a v0.9.4 -m "Release v0.9.4"
git push origin v0.9.4
docker manifest inspect ghcr.io/h4ckbu7eer-sudo/lucentmist:0.9.4
```

精确回滚不要只依赖可变 tag，应使用：

```bash
docker pull ghcr.io/h4ckbu7eer-sudo/lucentmist@sha256:11b2bdcd909697e1509370231daf06f1bd56c25beb38d251774bc3f96d41d2af
```

`main` 在发布后使用 `0.9.5-dev`，后续修复进入新的 `0.9.5` 发布，不覆盖 `0.9.4`。

生产环境必须显式配置强 `LMIST_API_TOKEN`、`LMIST_WEB_USER` 与 `LMIST_WEB_PASSWORD`。compose 自动生成并写入日志的演示凭据仅适合本地验证。
