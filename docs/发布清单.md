## 发布命令

```bash
dotnet restore --locked-mode
dotnet format --verify-no-changes --no-restore
dotnet build -c Release --no-restore
dotnet test -c Release --no-build
docker compose config --quiet
git diff --check

git push origin main
git tag -a v0.9.5 -m "Release v0.9.5"
git push origin v0.9.5
gh run view <tag-run-id>
git ls-remote --tags origin v0.9.5
docker manifest inspect ghcr.io/h4ckbu7eer-sudo/lucentmist:0.9.5
```

0.9.4 用户应升级到 0.9.5，以获得 OSV 诚实化、SSL/UDP/CVE 正确性及扫描并发修复。精确回滚摘要见各自的发布说明；不要把可变标签当作不可变回滚点。

生产环境必须显式配置强 `LMIST_API_TOKEN`、`LMIST_WEB_USER` 与 `LMIST_WEB_PASSWORD`。compose 自动生成并写入日志的演示凭据仅适合本地验证。
