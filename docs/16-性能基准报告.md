# LucentMist 性能基准报告

> 日期: 2026-08-09
> 工具: BenchmarkDotNet v0.15.8
> 运行方式: `dotnet run -c Release --project tests/LucentMist.Benchmarks -- --filter *`

## 1. 硬件与运行环境

| 项目 | 值 |
|------|----|
| CPU | 12th Gen Intel Core i7-12650H 2.30GHz，10 核 16 线程 |
| 操作系统 | Windows 11 23H2 (10.0.22631) |
| .NET 运行时 | .NET 10.0.10 |
| 目标网络 | Ping: `127.0.0.0/24`（254 IP，回环网段）；Port/UDP: `127.0.0.1` |
| 基准策略 | ShortRun（Warmup=3，Iteration=3，Launch=1） |

> 注意：Ping 基准使用回环网段，不能代表物理局域网的真实 ICMP 延迟，但可验证并发扩展性与工具本身开销。真实子网耗时主要由 ICMP 超时与网络延迟决定。

## 2. 实测结果

### 2.1 Ping 存活扫描（/24，254 IP，单次超时 300ms）

| 并发 | Mean | StdDev | Allocated |
|------|------|--------|-----------|
| 50 | 18.59 ms | 2.579 ms | 439.56 KB |
| 100 | 18.25 ms | 0.491 ms | 438.41 KB |
| 200 | 16.97 ms | 2.111 ms | 438.70 KB |

### 2.2 TCP 端口扫描（1000 端口，单端口超时 100ms）

| 并发 | Mean | StdDev | Allocated |
|------|------|--------|-----------|
| 10 | 10,995.77 ms | 12.839 ms | 3024.23 KB |
| 50 | 2,194.49 ms | 2.842 ms | 3020.79 KB |
| 100 | 1,096.75 ms | 3.978 ms | 3016.49 KB |

### 2.3 UDP 端口扫描（6 端口，单端口超时 400ms）

| 并发 | Mean | StdDev | Allocated |
|------|------|--------|-----------|
| 1 | 816.31 ms | 3.949 ms | 582.63 KB |
| 5 | 407.32 ms | 1.552 ms | 608.89 KB |
| 10 | 408.16 ms | 1.320 ms | 608.89 KB |

## 3. 与 PRD 承诺对标

| PRD 承诺 | 实测 | 结论 |
|----------|------|:--:|
| 单次 /24 存活扫描 < 30 秒 | 回环 /24 实测 17-19 ms（300ms 超时） | ✅ 达标（回环环境） |
| 端口扫描 100 端口 < 60 秒 | 1000 端口并发 10 约 11.0s，折算 100 端口约 1.1s | ✅ 达标 |
| UDP 扫描 | 无 PRD 承诺，提供基线 | 记录 |

当前所有基准均达标，无需红色标注。

## 4. 结论与建议

- TCP 端口扫描并发收益显著：并发 10→100，1000 端口耗时从约 11.0s 降到约 1.1s。
- UDP 扫描受单端口超时限制，并发从 1 提升到 5 后收益明显，继续提升到 10 无进一步收益，说明当前瓶颈在探测逻辑而非并发。
- 生产环境建议：Ping 扫描超时 1000-3000ms、并发 50-200；TCP 端口扫描超时 100-1000ms、并发 50-100；UDP 扫描超时 1000-3000ms、并发 5-20。
