## 3. 踩坑记录（可复用）

### 3.1 API net8 无法集成测试
- 现象: WebApplicationFactory 测试 500，`PipeWriter.UnflushedBytes` 异常
- 根因: API 是 net8.0 + RollForward，测试项目 net10.0，net8 的 Mvc.Testing/TestServer 与 net10 STJ 不兼容
- 解法: **API 升 net10.0**，与 Web/tests 统一；Mvc.Testing 升 10.0.10
- 教训: 同解决方案里"库 net8 + 宿主 net10"可行（纯库无 ASP.NET 依赖），但**ASP.NET 应用 + 测试必须同 TFM**

### 3.2 record 位置参数请求模型绑定坑
- 现象: `AgentChatRequest(string Message)` 收 JSON `{"message":...}` 返回 400
- 根因: record 主构造参数匹配区分大小写
- 解法: 请求模型改普通类（setter 属性），ASP.NET 大小写不敏感绑定生效

### 3.3 Windows 中文 JSON 400
- 现象: curl 发中文 body 400，ASCII 正常
- 根因: bash/curl 在 GBK 控制台下编码错乱，非服务端 bug
- 解法: 客户端用 UTF-8（Python requests/Postman/浏览器）

### 3.4 testhost 僵尸进程
- 现象: 后台跑 `dotnet test` 残留 testhost 占 5-10GB 内存
- 解法: 测试前停用/测试后 `Stop-Process testhost` 清理

### 3.5 Docker 缺 Web 服务
- 现状: Dockerfile 只发布 net8 API/CLI，runtime:8.0，不含 net10 Web
- 结论: v0.5.0 已知缺口，v0.6.0 需补 Web 发布 + aspnet:10.0
