## 1. 部署方式

### 1.1 本地部署（开发/测试）

**步骤：**

```bash
# 1. 确认环境
dotnet --version  # 需要 8.0+

# 2. 编译项目
cd /opt/LucentMist  # 或 E:\LucentMist
dotnet build -c Release

# 3. 发布
dotnet publish src/LucentMist.CLI -c Release -o publish/cli
dotnet publish src/LucentMist.API -c Release -o publish/api

# 4. 运行
./publish/cli/lmist status
./publish/api/LucentMist.API
```

### 1.2 Docker 部署

**Dockerfile（示例）：**

```dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY . .
RUN dotnet publish src/LucentMist.API -c Release -o /app

FROM mcr.microsoft.com/dotnet/aspnet:8.0
WORKDIR /app
COPY --from=build /app .
EXPOSE 5050
ENTRYPOINT ["dotnet", "LucentMist.API.dll"]
```

**构建与运行：**

```bash
docker build -t lucent-mist:0.1.0 .
docker run -d \
  --name lucent-mist \
  -p 5050:5050 \
  -v ./config:/app/config \
  -v ./data:/app/data \
  lucent-mist:0.1.0
```

### 1.3 systemd 服务（Linux）

```ini
# /etc/systemd/system/lucentmist-api.service
[Unit]
Description=LucentMist API Service
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/LucentMist
ExecStart=/opt/LucentMist/publish/api/LucentMist.API
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable lucentmist-api
sudo systemctl start lucentmist-api
```

## 2. 配置文件完整说明

### 2.1 配置文件位置

```
config/
├── appsettings.json           # 主配置文件
├── secrets.json               # 敏感信息（API Key 等，不提交 Git）
└── prompts/
    └── system_prompt.txt      # AI 系统提示词
```

### 2.2 环境变量覆盖

所有配置项均可通过环境变量覆盖，格式：`LucentMist__{Section}__{Key}`

```bash
# Linux/macOS
export LucentMist__LLM__Provider=claude
export LucentMist__LLM__ClaudeApiKey=sk-ant-api03-xxx

# Windows
set LucentMist__LLM__Provider=claude
set LucentMist__LLM__ClaudeApiKey=sk-ant-api03-xxx
```

优先级：**环境变量 > secrets.json > appsettings.json**

### 2.3 安全配置建议

- **生产环境**：使用 `secrets.json` 存储 API Key
- **开发环境**：Ollama 本地运行无需 API Key
- **API 鉴权**：设置 `API.AuthToken`，客户端在 Header 中携带 `Authorization: Bearer <token>`

## 3. 日志管理

### 3.1 日志级别

| 级别 | 说明 | 适用场景 |
|------|------|----------|
| Debug | 详细信息 | 开发调试 |
| Information | 常规信息 | 生产默认 |
| Warning | 警告事件 | — |
| Error | 错误事件 | 排查问题 |

### 3.2 查看日志

```bash
# 文件日志
tail -f logs/lucentmist.log

# 控制台日志（开发环境）
DOTNET_ENVIRONMENT=Development dotnet run --project src/LucentMist.API

# 过滤特定级别
grep "ERROR" logs/lucentmist.log
```

### 3.3 日志轮转

日志文件位于 `logs/` 目录。建议配置日志轮转（logrotate 或 script）：

```
# /etc/logrotate.d/lucentmist
/opt/LucentMist/logs/*.log {
    daily
    rotate 7
    compress
    missingok
    notifempty
}
```

## 4. 性能调优

### 4.1 扫描参数

| 参数 | 默认值 | 建议 |
|------|--------|------|
| `Scan.DefaultTimeoutMs` | 5000 | 内网保持；外网可增至 10000 |
| `Scan.MaxConcurrency` | 100 | 局域网内可增至 200-500 |
| `Scan.RateLimitPerSecond` | 50 | 避免触发防火墙限制 |

### 4.2 Agent 参数

| 参数 | 默认值 | 建议 |
|------|--------|------|
| `Agent.ReActMaxRounds` | 10 | 复杂任务可增至 15 |
| `LLM.MaxTokens` | 4096 | 长回复可增至 8192 |
| `LLM.Temperature` | 0.7 | 精确任务降为 0.3 |

### 4.3 资源最优配置

| 场景 | 并发 | 超时 | 模型 |
|------|------|------|------|
| 家庭网络 (< 50 设备) | 50 | 3000 | qwen2.5:3b |
| 小型办公室 (50-200) | 100 | 5000 | qwen2.5:7b |
| 大型网络 (200+) | 200 | 10000 | claude-sonnet-4-6 |

## 5. 数据存储

### 5.1 SQLite 数据库

```bash
# 数据库位置（默认）
data/lucentmist.db

# 备份
cp data/lucentmist.db data/lucentmist.db.backup.$(date +%Y%m%d)

# 恢复
cp data/lucentmist.db.backup.20260726 data/lucentmist.db

# 查看表结构
sqlite3 data/lucentmist.db ".tables"
sqlite3 data/lucentmist.db ".schema devices"
```

### 5.2 Redis 缓存（可选）

```bash
# 连接测试
redis-cli -h localhost -p 6379 ping

# 查看 LucentMist 缓存
redis-cli keys "scan:*"
redis-cli keys "agent:*"

# 清空缓存
redis-cli keys "scan:*" | xargs redis-cli del
```

### 5.3 备份策略

```bash
#!/bin/bash
# 每日备份脚本 backup.sh
BACKUP_DIR="/backup/lucentmist/$(date +%Y%m%d)"
mkdir -p "$BACKUP_DIR"

# 备份数据库
cp data/lucentmist.db "$BACKUP_DIR/"

# 备份配置
cp -r config "$BACKUP_DIR/"

# 保留最近 7 天
find /backup/lucentmist -maxdepth 1 -mtime +7 -exec rm -rf {} \;
```

## 7. 升级指南

### 7.1 升级步骤

```bash
# 1. 备份
cp -r config config.backup
cp data/lucentmist.db data/lucentmist.db.backup

# 2. 拉取新版本代码
git pull origin main

# 3. 编译
dotnet build -c Release

# 4. 发布
dotnet publish src/LucentMist.API -c Release -o publish/api

# 5. 重启服务
systemctl restart lucentmist-api  # systemd
# 或
docker restart lucent-mist         # Docker
```

### 7.2 回滚方案

```bash
# 1. 恢复备份
cp -r config.backup/* config/
cp data/lucentmist.db.backup data/lucentmist.db

# 2. 切换到旧版本
git checkout v0.0.X

# 3. 重新编译部署
dotnet publish -c Release -o publish/api
systemctl restart lucentmist-api
```

### 7.3 数据库迁移

当前版本数据库结构不变，跨版本升级一般无需迁移。如遇新版本有 schema 变更：

```bash
# 备份数据库后
sqlite3 data/lucentmist.db < migrations/v0.2.0_up.sql
```

## Web 管理界面部署 (v0.3.0 新增)

### 本地启动

```bash
dotnet run --project src/LucentMist.Web
# 默认 http://localhost:5050
```

### Docker 部署

```bash
docker build -t lucentmist-web:0.3.0 -f src/LucentMist.Web/Dockerfile .
docker run -d -p 5050:5050 --name lucentmist-web lucentmist-web:0.3.0
```

### 自定义端口

```bash
dotnet run --project src/LucentMist.Web -- 8080
```

### 生产环境建议

- 使用 Nginx 反向代理 + HTTPS
- 配置 `ASPNETCORE_ENVIRONMENT=Production`
- 限制 SignalR 连接数 (`builder.Services.AddSignalR(o => o.MaximumReceiveMessageSize = 64KB)`)
